水球爆爆大作戰

Water Bomb Battle

Canvas 2D Context API Web Audio API (音效合成) Touch & Pointer Events requestAnimationFrame

現金流量表智慧分析

Cash Flow Statement

作品簡介

應用場景 適用於上市櫃公司財務體質快篩、高階主管營運資金規劃、個人基本面投資決策，以及財務課程教學實務演示。

🛡️ 資安與機密脫敏 04
🔒

資料去識別化防護

Data Anonymizer

作品簡介

針對企業機密防護與個資合規所設計的前端脫敏工具。所有去識別化運算完全在使用者瀏覽器本地端執行，資料絕不上傳雲端，確保零外洩風險。提供 SHA-256 雜湊演算法、電話與身分證遮罩及多欄位規則替換，並原生支援 Excel 與 CSV 檔案批次解析與匯出，兼顧安全與作業效率。

使用技術 & API

CryptoJS (SHA-256 雜湊加密) SheetJS (XLSX/CSV 處理) FileReader API (本地二進位讀取) Lucide Web Icons API
應用場景 適用於資料釋出前敏感個資遮罩、提供廠商測試資料保護、AI 模型訓練資料脫敏處理，以及企業法令遵循資安規範。
